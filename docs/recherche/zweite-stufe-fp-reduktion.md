# Second-stage FP reduction for two-stage lesion detectors — literature scan

Scope: CMB candidate classification / FP reduction, then transferable ideas from lung-nodule FP reduction (LUNA16), brain metastases, aneurysms, lacunes, MS lesions.
Budget used: ~23 web searches/fetches (over the ~15 target — the 5-question x 6-domain scope needed the extra passes; stopped there).
Method note: most facts below come from search-engine result snippets/AI summaries of abstracts, not full-text reads (two direct WebFetch attempts on primary PDFs/PMC pages were blocked by a CAPTCHA/verification wall). Precise multi-decimal numbers with clear provenance are reported as-is; everything not read at the primary source is tagged **(unverified)**. Training-set / candidate-count numbers were essentially never stated in the abstracts/snippets we could reach — marked "not found" throughout rather than guessed.

Our setting for reference: Stage-1 anisotropic 3D U-Net (T2*-GRE + FRST channel, BCE+Dice+blob loss, deliberately sensitive) → connected components above p=0.05-0.15 after SynthSeg CSF rule → ~280-370 candidates/57 CV cases, ~115 positives, candidates cover 77-79% of lesions; +830 CMB private T2* cohort, +650 SWI. Per-candidate patch 40x40x20 @ 0.5x0.5x1mm, channels {T2*, FRST, stage-1 prob} + SynthSeg tissue labels; no phase/QSM/T1, FLAIR only for a subgroup. Already tried (nested 5-fold CV): probability threshold alone; logistic regression / random forest on 10 handcrafted features (best so far, F1 0.62); small 3D ResNet on 32x32x16 crops, flips + random offsets, 3 seeds averaged (F1 0.60, worse — too few positives); Frangi vesselness post-filter (no effect).

## Top 8 second-stage options for our pipeline

Ranked by expected gain per effort given our small candidate set (few hundred to few thousand candidates, current best = logistic regression F1 0.62, CNN currently worse):

1. **Gradient-boosted trees (XGBoost/LightGBM) on our existing 10 handcrafted features** — cheapest possible next step on the exact paradigm (tabular features) that already beats our CNN; lung-nodule CADx literature reports GBT beating RF/SVM on the same kind of features (Q3 #8).
2. **Add cheap new candidate features: ensemble/seed-disagreement (already computed, currently discarded) + MIP/MinIP vessel-continuity + topology/shape descriptor** — near-zero marginal cost, directly targets our known unresolved FP class (vessels, where Frangi failed) from three different angles (Q2 #1/#3/#6, Q4 #1, Q5 #6).
3. **Chain two lightweight classifiers (Stage A full recall → Stage B refines only Stage-A positives)** instead of one — the closest published analog (2026 geometric-to-neural cascade) cut 76.8% of remaining FPs this way on a near-identical CMB pipeline (Q1 #9).
4. **Focal loss or OHEM when retraining the 3D ResNet discriminator** — cheap loss/sampler change that directly targets the stated CNN failure mode ("too few positives"), well-established for exactly this imbalance problem (Q3 #1/#2).
5. **Pretrain the 3D ResNet encoder before fine-tuning** — either self-supervised (Models Genesis-style restoration tasks on our own unlabeled crops/volumes) or via a supervised 3D medical backbone (MedicalNet/Med3D) — addresses the root cause ("too few positives to train a CNN from scratch") rather than just its symptoms (Q3 #5/#6).
6. **Physics-guided synthetic positive CMBs and synthetic hard negatives, injected fold-wise** — strongest and most current published evidence (CenSynCMB, 2026) on our exact benchmark (VALDO Task 2); more engineering effort (needs a simulator) but targets sample size directly, including the hard-negative side we struggle with (Q1 #10, Q3 #4).
7. **Knowledge distillation from a whole-volume teacher (our own stage-1 U-Net, or a larger one) into the patch-based discriminator** — gives the discriminator soft-label supervision beyond hard 0/1 labels, MicrobleedNet's approach to the same few-positives problem (Q1 #5).
8. **TTA-consistency as an added candidate feature** (score each candidate under a few test-time flips/offsets, use the variance) — cheap, reuses augmentation already in the pipeline, complements #2's free-feature approach (Q4 #2).

Deliberately not in the top 8: collapsing to a single end-to-end detector (nnDetection/Retina U-Net) — mixed/negative evidence specifically for tiny lesions, and a closely analogous two-stage brain-metastases system was reported to beat one-stage baselines (Q5 #2/#3), so this looks like the wrong direction for us right now rather than an untried opportunity.

## Follow-up by the project (2026-09-20, evening) -- what was checked against our own data

- Shortlist #1 (gradient-boosted trees on the existing 10 features): TESTED, no gain (VALDO blob candidates 0.609 vs logistic 0.623; private T2* cohort 0.655 vs
  probability threshold 0.670). The classifier family is not the bottleneck; the features carry nothing the first stage has not already used.
- Shortlist #2, "seed disagreement (already computed)": it was NOT computed before -- now it is (`cmb/analysis/ensemble.py`). Two-seed mean of the baseline on VALDO:
  cross-selected F1 0.647 vs 0.622 / 0.564 for the members, FP per case 0.82 vs 1.02 / 1.09, paired +0.025 [-0.024; +0.079] against the better member.
- Shortlist #4 (focal loss / OHEM) does not fit: our candidate sets are roughly balanced (115:169, 582:379), there is no flood of easy negatives.
- Shortlist #3 (two chained classifiers): the second one would see even fewer examples than the first; parked.
- CenSynCMB (arXiv 2607.05325) abstract verified at the source by the project: authors He, Zhang, Li, Saccoh, Ingala, Rehwald, de Bruijne, Barkhof, Davies, Sudre;
  submitted 2026-07-06; VALDO Task 2 lesion-level F1 74.3 % (p = 0.020), AIBL SWI recall 88.5 %, F1 65.0 %. Matching rule and data split not read yet.
- Budget note: the scan used 23 fetches (target 15). All "(unverified)" entries must be read at the source before they are cited.
- CenSynCMB full text read by the project (arXiv HTML, 2026-09-20): 72 VALDO cases, 5-fold CV stratified by CMB presence, centroid-within-5-mm one-to-one matching, F1 per
  subject then macro-averaged; inputs T1+T2+T2* at 1 mm isotropic; 200 epochs, 96^3 patches 2:1, threshold 0.5, < 5 voxels removed. Table I F1: CenSynCMB 74.3, Attention U-Net
  65.8, FRST-style 63.3, DynUNet 61.3, Zihao (VALDO team) 61.1, SwinUNETR 54.3. Ablation: backbone 65.8, + FN reweighting 67.6, + centre map 70.3, both 71.7, + synthetic CMB 73.1,
  + synthetic mimics 74.3. No code released.
- Ensembles beyond two members (built from existing runs with identical folds) do not extend the gain: fixed cell with CSF rule 0.647 / 0.648 / 0.630 / 0.639 for 2 / 3 / 5 / 6
  members against single models 0.59-0.65 (mean 0.609). Ensemble ~ best member, +0.02 to +0.04 above the average member.
